# Version 1.0.0

## Initial Release

### Features
- **ChainedBlockSource Optimization**: Replace enhanced for loop with indexed loop for faster blockstate sampling

- **Faster Chunk Unlocking**: Replace enhanced for loop with indexed loop for faster chunk section unlocking
