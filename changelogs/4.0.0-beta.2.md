# 4.0.0-beta.2 (1.21–1.21.1)

### Density hot path (parity-preserving)

- **RegistryEntryHolder** — cache unwrapped `DensityFunction` (drop per-sample `value()` + cast)
- **BinaryOperation** — faster `sample`; ADD `fill` reuses ThreadLocal buffer (no per-call `new double[]`)
- **LinearOperation** — direct mul/add + bulk fill special cases (×0, ×1, +0)
- **UnaryOperation** — inlined abs/square/cube/half/quarter negative; squeeze matches vanilla
- **RangeChoice** — hoisted fields; same in/out branch as vanilla

### Notes

Still does **not** replace Perlin noise or rewrite the full density graph — attacks call overhead and allocation on the hottest node types seen in Spark.
