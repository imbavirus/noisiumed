# Version 3.0.2

## Bug Fix Release

This release fixes an issue where the incorrect jar file was being uploaded to CurseForge and Modrinth.

### Changes

- **Publishing Fix**: Fixed `publish.ps1` script to upload the correct NeoForge jar file (`neoforge/build/libs/noisiumed-*-neoforge-*.jar`) instead of the empty root build jar
- **Build Artifacts**: Publishing scripts now correctly identify and upload the mod jar containing all required metadata and class files

### Technical Notes

- The correct jar file includes `META-INF/neoforge.mods.toml` and all mod resources
- GitHub Actions workflows were already correctly configured; this fix ensures local publishing scripts match that behavior
