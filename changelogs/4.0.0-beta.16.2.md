# 4.0.0-beta.16.2 (1.21-1.21.1)

### Memoized interpolator deep specialize

beta.16 cratered wall by rebuilding Spec trees for every interpolator every chunk.
beta.16.1 left interpolator deep off.

**This release:** per-NoiseChunk `IdentityHashMap` memo for deep rewrite (shared Spec subtrees).

**Bench (interpolators ON):** golden **14/25**, multi avg **+3.3% vs FN**, but quiet runs
still ~1–2s behind FN (no disaster — memo fixed the 3× wall). Default leaves interpolators
**off**; CellCache deep stays on (β16.1 profile).

| Flag | Default |
|------|---------|
| `-Dnoisiumed.density.deep` | true (CellCache) |
| `-Dnoisiumed.density.deep.interpolators` | **false** (try `true` — memoized) |

Enable experiment: `-Dnoisiumed.density.deep.interpolators=true`.
