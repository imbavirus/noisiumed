# 4.0.0-beta.16.1 (1.21-1.21.1)

### Turnaround after beta.16 deep-specialize failure

**What went wrong in beta.16**

1. **Deep specialize rewrote every DensityInterpolator.delegate** per NoiseChunk → full Spec tree allocation on dozens of interpolators × thousands of chunks → wall ~3× worse + garbage storms.
2. **Shared `DensityScratch` temp** under nested Spec/Ap2 `Add.fill` clobbered intermediates → 0/25 golden when deep+nest interacted badly.
3. Default then flipped deep **off**, so we shipped no CellCache win either.

**What we ship now**

| Change | Default |
|--------|---------|
| Nested fill stack temps | on (correctness) |
| **Deep specialize CellCache.delegate only** | **on** |
| Deep specialize interpolator delegates | **off** (`-Dnoisiumed.density.deep.interpolators=true`) |
| Clamp SpecDensity | on (`-Dnoisiumed.density.clamp=false` to bisect) |
| `isPureArithmeticTree(SpecDensity)` | uses `original` snapshot (not “always pure”) |

Disable all deep: `-Dnoisiumed.density.deep=false`.
