# 4.0.0-beta.14 (1.21-1.21.1)

### Accuracy on non-L1 optims

| Opt | Change |
|-----|--------|
| **NC-3 cell grid** | Default **off**. Only activates when exactly **one** `CACHE_ALL_IN_CELL` wrap exists (ambiguous multi-cache graphs refuse NC-3). OOB indices fall back to vanilla `blockStateSampler`. |
| **Fast ore** | Default **on** again (no re-specialize of vein DFs — that was the ore parity bug). |
| **Aquifer specialize** | Stays default **off** (not pure arithmetic graphs). |
| **Holder resolve** | Cache unwrap only; **no** specialize on shared registry holders. |
| **Surface skip** | Only when **all sections empty** (drop L1 solid-flag shortcut). |

L1 heightmap-before-surface fix from beta.13 remains.
