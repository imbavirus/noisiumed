# Version 2.0.0

## Multiloader Support

### Changes
- **Forge Support**: Added Forge modloader support
- **NeoForge Support**: Added NeoForge modloader support
- **GenerationShapeConfig Caching**: Added caching for `horizontalCellBlockCount` and `verticalCellBlockCount` to skip repeated `BiomeCoords#toBlock` calls
- **Improved Compatibility**: Rewrote main `NoiseChunkGenerator#populateNoise` optimization using `@Inject` and `@Redirect` instead of `@Overwrite` for better mod compatibility (ReTerraForged, Nether Depths, Lost Cities)
