# 4.0.0-beta.12 (1.21-1.21.1)

### Measurement + open aquifer

1. **Golden section hashes** — `bench/parity_hash.py` + `bench/Run-ParityHash.ps1`  
   Hashes overworld chunk block-state sections (palette + packed data) for a seed/radius; compares spark-only baseline vs Noisiumed.

2. **Open aquifer** — specialize aquifer density graphs at `AquiferSampler.Impl` construction  
   (`barrier`, floodedness, spread, type, erosion, depth).  
   Flag: `-Dnoisiumed.aquifer.specialize=false`  
   Metrics: `aq_spec=`

3. **Ore A/B flag** — `-Dnoisiumed.fast.ore=false` restores vanilla ore lambda (default monomorphic on).

4. **Bench watchdog** — `max-tick-time=-1` in Spark / parity harness server.properties.
