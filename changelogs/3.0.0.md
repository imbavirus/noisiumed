# Version 3.0.0

## Initial Fork Release

This version marks the fork of Noisium as Noisiumed, with minor performance improvements and project restructuring.

### Changes

- **Forked from Noisium**: Created Noisiumed as a maintained fork of [Noisium](https://github.com/Steveplays28/noisium) by Steveplays28
- **Mod ID Renamed**: Changed mod identifier from `noisium` to `noisiumed`
- **Version Bump**: Major version bump to distinguish fork releases from upstream
- **Minor Performance Improvement**: Cached `samplers.size()` in `ChainedBlockSourceMixin` to avoid repeated method calls in hot path

### Technical Notes

- Based on Noisium v2.7.0 (Minecraft 1.21-1.21.1)
- All original optimizations preserved
- Compatible with NeoForge 21.1.22+
