# 4.0.0-beta.16 (1.21-1.21.1)

### Density / fill hardening (wall-clock foundation)

| Change | Detail |
|--------|--------|
| **Nested fill safety** | `DensityScratch` depth-stack temps — nested Spec/Ap2 `Add.fill` no longer clobber a shared buffer (latent golden-hash corruption under deep trees). |
| **Clamp SpecDensity** | Specialize `DensityFunctionTypes.Clamp` → monomorphic fill/sample. |
| **Deep specialize (opt-in)** | After NoiseChunk ctor, rewrite CellCache + DensityInterpolator `delegate`s. **Default off** (`-Dnoisiumed.density.deep=true`) — improves monomorphy but currently regresses FULL golden vs beta.15. |
| **Coverage metrics** | PathMetrics: `spec_deep`, `spec_nodes`, `vanilla_arith` (when deep on). |

### Flags
- `-Dnoisiumed.density.specialize=false` — disable all SpecDensity
- `-Dnoisiumed.density.deep=true` — enable experimental deep delegate rewrite
