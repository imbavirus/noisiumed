# 4.0.0-beta.15 (1.21-1.21.1)

### Accuracy without killing speed

| Opt | Fix (stays **on** by default) |
|-----|-------------------------------|
| **NC-3 cell grid** | Capture only CellCache for vanilla primary: `cacheAllInCell(add(finalDensity, beardifier))` — not arbitrary last cell cache. Solid early-out stays. |
| **Aquifer specialize** | `specializePure` only (pure arithmetic trees); noise-bearing graphs unchanged. |
| **Fast ore** | Monomorphic path, no re-specialize (unchanged). |
| **Surface skip** | L1 solid-flag + empty-section skip restored (heightmaps still flushed first). |
| **Holders** | Unwrap cache only (no global specialize). |

Disable if needed: `-Dnoisiumed.cell.density.grid=false`, `-Dnoisiumed.aquifer.specialize=false`, `-Dnoisiumed.fast.ore=false`.
